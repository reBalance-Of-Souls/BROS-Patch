# EXTRA MISSION NPC events (dcbossrush 0.9.2+), read beside dcbossrush.dll.
# 0.16.0: the roster redone from the EX Sprites -- 81 characters across the three realms.
#
# Meeting an NPC on the map draws one of their opening lines, then ONE response
# from their Choice A pool and ONE from their Choice B pool -- the two cards. So
# the same NPC offers different answers each time.
#
#   npc <chara id | -> <realm: hueco | soul | living> <name>   (- = no game character)
#   art <sprite> (0.16.0) the NPC's art: dcbossrush_map/spr_<sprite>.png (the encounter) and
#       sprg_<sprite>.png (grey, the map), from mk_npc_art.py and the EX Sprites folder
#   line <what they say>
#   exit <what they say as you leave, after their response> (0.10.3; one is picked)
#   desc <the pin's description on the map, bottom right> (0.14.0)
#   a | <chance %> | <effect> | <effect if it fails> | <card title> | <what it does> | <dialogue on success> | <dialogue on failure>
#   b | ... the same, for the Choice B pool
#
# chance 100 = a sure thing (its failure fields are ignored: use none and -).
# Below 100 is a gamble: the header marks it GAMBLE with its chance.
#
# effects:
#   none      nothing
#   heal      the next fight starts at full HP
#   kon       +1 Konpaku (and +1 to the run's Konpaku limit)
#   tali      +1 Spirit Talisman for this run       tali2   +2 talismans
#   crys      +1 Soul Crystal for this run          healtali  full HP and +1 talisman
#   sample    +1 Konpaku, but every later foe +10% attack
#   trade     one of this run's talismans for a Soul Crystal
#   cpudown   the next foe's CPU level -2           ward    the next foe -1 Konpaku
#   atkdown   the next foe -15% attack              hurt    the next foe +1 Konpaku
#   curse     the next foe +1 Konpaku and +20% attack
#   mend / mend_big     recover 25% / 50% Reishi (HP) now
#   bleed / bleed_big   lose 15% / 30% Reishi now (never kills)
#   kon_down  -1 Konpaku (after the first fight, never below 1)
#   lose_tali lose one of this run's talismans      lose_crys  lose one Soul Crystal
#   cpuup     the next foe's CPU level +2           atkup   the next foe +15% attack
#
# BATTLE effects (0.9.3) act inside the next fight -- or, with run: in front, every
# fight for the rest of the run. foe_ in front puts it on your opponent instead
# (foe_poison, run:foe_slow). Join several with + : fs_full+fragile
#   fs_full / fs_half / fs_empty   start with full / half / no Fighting Spirit
#   no_awaken          Fighting Spirit locked at 0: no Awakening, no Reawakening
#   frail / wounded    start at 50% / 75% Reishi (HP)
#   reishi_cap / reishi_cap_half   Reishi can't go above 75% / 50%
#   regen / regen_big  Reishi recovers through the fight (0.6% / 1.5% a second)
#   poison / poison_big   Reishi drains through the fight (0.4% / 1% a second; never kills)
#   swift / slow       move speed +20% / -20%
#   haste / sluggish   action (attack) speed +12% / -12%
#   strong / weak      damage dealt +20% / -20%
#   sturdy / fragile   damage taken -20% / +20%
#   glass              damage dealt AND taken +30%
#   berserk            full Fighting Spirit, damage taken +25%, guard at 40%
#   rev_full / rev_empty   start with a full / empty Reverse gauge
#   no_reverse         Reverse actions sealed
#   no_signature       Reiryoku held at 0: no Signature moves (experimental)
#   iron_guard / brittle_guard   guard never wears down / starts at 40%
#   evo                start Awakened (foe_evo: the foe; not Renji, Komamura,
#                      Dangai Ichigo or Mayuri)
#   sublimation        start Awakened AND in Kikon Channel (= kikon_channel)
#   spirit_drive       start Awakened AND in Spirit Drive (implies Kikon Channel)
#   unblockable        your attacks can't be guarded (foe_unblockable: the foe's)
#   no_spirit          no Fighting Spirit gained and no Awakening (foe_no_spirit:
#                      the foe); the gauge keeps what it starts with -- unlike
#                      no_awaken, which empties it
#   demote             one stage down at the start of the fight: Spirit Drive >
#                      Kikon Channel > Awakening > base, Reawakening > Awakening
#                      (you: from the state the last fight left you in; foe_demote:
#                      the foe starts one stage lower than its own / other effects)
#   kikon_channel      the same as sublimation
#   inverted           your controls are inverted: forward is back, left is right
#                      (keyboard and stick; you only -- the foe has no controls)
#   venom              Reishi drains like Uryu's Reawakening: ~2% of max a second,
#                      down to 30% and no further (paused during Kikon moves);
#                      foe_venom on the foe. poison is a gentler drain with no floor
# Card titles show on the card: keep them under about 22 characters.
