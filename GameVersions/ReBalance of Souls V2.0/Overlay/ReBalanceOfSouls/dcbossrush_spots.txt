# EXTRA MISSION flavor spots, read beside dcbossrush.dll.
#
# A flavor spot is a small point on the path between fights: a place, an object or
# a minor encounter. Passing one costs no step. Each visit draws one of the spot's
# lines, then ONE card from its Choice A pool and ONE from its Choice B pool, so
# every a/b line must make sense against every line of the spot.
#
#   spot <realm: hueco | soul | living | any, or several joined with a comma: living,soul> <icon> <name>
#        (0.19.24; a name past about 26 characters wraps on the map)
#   desc <the pin's description: the map's bottom-right text and the Location screen> (0.14.0)
#   image <the Location screen's picture, in dcbossrush_map/> (0.14.0)
#   portal <hueco | soul | living> <the way in's description on the first screen> (0.14.0)
#   line <narration, second person, present tense> (one is picked each visit)
#   exit <closing narration after the outcome> (one is picked)
#   a | <chance %> | <effect> | <effect if it fails> | <card title> | <what it does> | <text on success> | <text on failure>
#   b | ... the same, for the Choice B pool
#   c | ... the same, for a third card (0.19.24: realm travel) -- dealt beside A and B where the
#       location has c lines; a card that travels to the realm the player is already in is never dealt
#
# Every spot needs at least one a line and one b line (16 max each; 0.19.24: was 3 each, by habit).
# chance 100 = a sure thing (its failure fields are ignored: use none and -).
# Below 100 is a gamble: the header marks it GAMBLE with its chance.
# Narration is not auto-quoted: put speech in straight double quotes yourself.
#
# icons: sand cave nest camp crate skull grave sword tree ruin storm rift tea medic
#        lab dojo shrine spring fire scroll sewer house school ghost chain bar
#        pillar candy book moon
#
# effects (join several with + : mend+tali):
#   none      nothing
#   heal      the next fight starts at full HP
#   mend / mend_big     recover 25% / 50% Reishi (HP) now
#   bleed / bleed_big   lose 15% / 30% Reishi now (never kills)
#   kon       +1 Konpaku (and +1 to the run's Konpaku limit)
#   kon_down  -1 Konpaku
#   tali      +1 Spirit Talisman for this run       tali2   +2 talismans
#   lose_tali lose one of this run's talismans
#   crys      +1 Soul Crystal for this run          lose_crys  lose one Soul Crystal
#   healtali  full HP and +1 talisman
#   sample    +1 Konpaku, but every later foe +10% attack
#   trade     one of this run's talismans for a Soul Crystal
#   cpudown   the next foe's CPU level -2           cpuup   the next foe's CPU level +2
#   ward      the next foe -1 Konpaku               hurt    the next foe +1 Konpaku
#   atkdown   the next foe -15% attack              atkup   the next foe +15% attack
#   curse     the next foe +1 Konpaku and +20% attack
#   0.19.24 (Bleach_Location_Events_All_33):
#   mend:<n> / bleed:<n>        recover / lose n% Reishi now (mend:40, bleed:20; bleed never kills)
#   atkdown:<n> / atkup:<n>     the next foe -n% / +n% attack (atkdown:25)
#   travel_hueco / travel_soul / travel_living   into that realm: the road ahead is redrawn as
#               that realm's once the location is done (a c card; never in an event's own route)
#   flask       the next time Reishi falls under 40% in a fight, +20% (once; the run keeps it)
#   Several of one: hurt+hurt+hurt = the next foe +3 Konpaku; kon+kon = +2 Konpaku.
#
# BATTLE effects work here too -- every one in dcbossrush_npc.txt (fs_full, swift,
# sturdy, foe_strong, foe_no_awaken, foe_evo, foe_sublimation, foe_spirit_drive,
# foe_unblockable, unblockable, foe_no_spirit, no_spirit, demote, inverted, venom ...), with run: and foe_ in front as described there.
#
# BATTLE effects act inside the next fight -- or, with run: in front, every fight
# for the rest of the run. foe_ in front puts it on your opponent instead
# (foe_poison, run:foe_slow).
#   fs_full / fs_half / fs_empty   start with full / half / no Fighting Spirit
#   no_awaken          Fighting Spirit locked at 0: no Awakening, no Reawakening
#   frail / wounded    start at 50% / 75% Reishi (HP)
#   reishi_cap / reishi_cap_half   Reishi can't go above 75% / 50%
#   regen / regen_big  Reishi recovers through the fight
#   poison / poison_big   Reishi drains through the fight (never kills)
#   swift / slow       move speed +20% / -20%
#   haste / sluggish   action (attack) speed +12% / -12%
#   strong / weak      damage dealt +20% / -20%
#   sturdy / fragile   damage taken -20% / +20%
#   glass              damage dealt AND taken +30%
#   berserk            full Fighting Spirit, damage taken +25%, guard at 40%
#   rev_full / rev_empty   start with a full / empty Reverse gauge
#   no_reverse         Reverse actions sealed
#   iron_guard / brittle_guard   guard never wears down / starts at 40%
#   0.19.24:
#   fs_up:<n> / fs_down:<n>      start with n% more / less Fighting Spirit (of the gauge it is on)
#   fs_gain:<n>                  Fighting Spirit gained +n%
#   guard_dmg:<n>                your attacks wear the foe's guard n% faster
#   sp_strong (:<n>)             SP moves (sp_atk / sp_overatk / sp_step_atk) deal +20% (+n%)
#   Any percentage takes a number: strong:8 (+8% damage dealt), fragile:15, slow:15, weak:15,
#   regen:1 (1% of max Reishi a second), and regen / poison a time in seconds too: poison:1:40 =
#   lose 1% a second for the first 40 seconds. run: and foe_ go in front as before (run:strong:8).
# Card titles show on the card: about 22 characters fit one line; a longer one takes two (0.19.24).
