# While a line types out, a short "blip" plays every few letters, pitched to the speaker -- the
# old JRPG way of giving unvoiced dialogue a voice. One line per speaker:
#
#   <key> <voice>
#
# key   the speaker's sprite name (the `art` / `say` key: kisuke_urahara), a fighter as plNNN
#       (pl010), or the name a line shows, lower case with _ for spaces (rowdy_senior)
# voice deep | male | young | female | girl | neutral | none -- or a pitch in Hz (60..2000)
#         deep 220 Hz, male 300, young 360 (teenage boys), female 500, girl 620 (children),
#         neutral 400 (an unnamed speaker not listed here), none = silent
#
# A named speaker not listed blips neutral; narration (no name) is silent.
# Loudness: blip_volume 0..100 in dcbossrush.txt (0 = off).
